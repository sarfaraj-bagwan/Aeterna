# Contributing to Aeterna

Thank you for your interest in contributing to Aeterna. We are building a high-integrity, decentralized operating system for governance, and your help is vital.

## 🌟 Code of Conduct
By participating in this project, you agree to abide by our [Code of Conduct](./CODE_OF_CONDUCT.md).

## 🛠 How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issue Tracker.
- Provide a clear, descriptive title.
- Include steps to reproduce the issue.
- Describe the expected vs. actual behavior.

### Suggesting Enhancements
- Open a "Feature Request" in the GitHub Issues.
- Explain the benefit to the "Village Node" (Layer 0).
- Detail how it fits into the Seven-Layer Stack.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`npm test`).
5. Make sure your code lints (`npm run lint`).

## 📐 Development Workflow

### Technical Stack
- **Frontend:** React + Vite + Tailwind CSS
- **AI Core:** Gemini 1.5/2.0 API (via `@google/genai`)
- **State Management:** Functional React Hooks
- **Styling:** Design System rooted in *Swiss Grid* and *Brutalist* principles.

### Documentation Standards
All technical documentation resides in the `/docs` directory. We follow a "Documentation as Code" philosophy.
